# ATM Management System

A Java-based ATM simulation project built using Object-Oriented Programming concepts.

## Features

- Check Balance
- Deposit Money
- Withdraw Money
- Menu Driven Interface
- Encapsulation Implementation

## Technologies Used

- Java
- Eclipse
- Git
- GitHub

## How to Run

1. Open the project in Eclipse.
2. Run `ATMProject.java`.
3. Follow the menu options.
